# AI Business Assistant

## Présentation

**AI Business Assistant** est un atelier de Prompt Engineering visant à créer et améliorer des prompts pour différentes tâches d'entreprise : documents, analyse de données, Machine Learning et questions avec un LLM.

**LLM utilisé :** ChatGPT

## Contenu de l'atelier

L'atelier est composé de 9 parties :

1. **Anatomie d'un prompt**
2. **Techniques de prompting** : Zero-shot, One-shot, Few-shot
3. **Prompt Engineering et raisonnement**
4. **Sorties structurées et JSON**
5. **Prompts pour les applications métier**
6. **Prompt Engineering pour le Machine Learning**
7. **Prompt Engineering et RAG**
8. **Évaluation et optimisation des prompts**
9. **Bonus**

## Livrable

Le dossier contient :

* les prompts réalisés ;
* les résultats des tests ;
* les comparaisons ;
* les captures d'écran ;
* le document final de l'atelier.



## Git

Le livrable est mis à jour après chaque tâche avec un commit explicite.

Exemple :

```bash
git add .
git commit -m "Ajout de la partie 1"
git push
```
